# GMD Phase 1.3-web — Карта ребёнка в кабинете родителя (design)

**Дата:** 2026-04-19
**Фаза:** 1.3-web
**Предшественник:** v0.10.0 (Phase 1.3 — Location Ingestion backend)
**Релизная цель:** v0.11.0

## 1. Область и не-область

### Что входит

- Страница `/cabinet/children/[id]/map` с Яндекс.Картой v3.
- Маркер последней позиции через `GET /children/:id/location/latest`, polling 15с.
- Трек за выбранный день через `GET /children/:id/locations?from&to&order=asc&limit=2000`.
- Селектор даты: 3 чипа (Сегодня/Вчера/Позавчера) + `<input type="date">` с `min = now − 30d`.
- Индикатор устаревания (`ageSec` из API, 4 градации).
- Entry-point: кнопка «📍 На карту» на `ChildCard` в `/cabinet/children`.

### Что НЕ входит

- Геозоны на карте — Phase 2.
- Кластеризация остановок (stops) на треке — Phase 2.
- Bearing-стрелка направления — Phase 2.
- Детальная страница ребёнка с вкладками (`/cabinet/children/[id]`) — Phase 2.
- Fullscreen, экспорт KML/GPX, multi-day — Phase 2.
- Клик по точке трека с тултипом (кроме start/end) — Phase 2.
- Client-side downsampling — ждём реальных профилей запросов.
- Server-side downsampling — откладывается из Phase 1.3 backend.
- Страница `/changelog` в web-кабинете (обновим CHANGELOG.md, страница — позже).

### `LocationsApi`

```ts
// apps/web/lib/api/locations.ts
import { apiFetch } from './client';

export interface LatestLocationDto {
  lat: number;
  lon: number;
  recordedAt: string; // ISO
  serverReceivedAt: string;
  accuracy: number | null;
  altitude: number | null;
  speed: number | null;
  bearing: number | null;
  batteryLevel: number | null;
  isCharging: boolean | null;
  provider: 'gps' | 'fused' | 'network' | null;
  ageSec: number;
}

export interface LocationDto {
  lat: number;
  lon: number;
  recordedAt: string;
  accuracy: number | null;
  speed: number | null;
  // bearing/battery/altitude — в history тоже присутствуют, но UI не использует в MVP
}

export interface LocationHistoryDto {
  items: LocationDto[];
  nextCursor: string | null;
}

export const locationsApi = {
  // null при 204 (ещё нет точек)
  getLatest: (childId: string) =>
    apiFetch<LatestLocationDto | null>(`/api/children/${childId}/location/latest`),

  getHistory: (childId: string, from: string, to: string, limit = 2000) =>
    apiFetch<LocationHistoryDto>(
      `/api/children/${childId}/location/history?from=${encodeURIComponent(from)}&to=${encodeURIComponent(to)}&order=asc&limit=${limit}`,
    ),
};
```

`apiFetch` должен корректно обработать `204 No Content` → вернуть `null` без парсинга JSON.

### `useLatestLocation(childId)`

```ts
useQuery({
  queryKey: ['location', 'latest', childId],
  queryFn: () => locationsApi.getLatest(childId),
  refetchInterval: () => (typeof document !== 'undefined' && document.hidden ? false : 15_000),
  refetchIntervalInBackground: false,
  refetchOnWindowFocus: true,
  staleTime: 10_000,
  retry: 1,
});
```

Ответы:

- `200` → `LatestLocationDto`.
- `204` → `null` (UI показывает empty-state).
- `404` (`child_not_found`) → throw → обработчик в компоненте: `toast.error('Ребёнок не найден')` + `router.replace('/cabinet/children')`.
- Прочие ошибки → `toast.error(...)`, карта не моргает (держим `keepPreviousData` через дефолт).

### `useLocationHistory(childId, date)`

```ts
const [from, to] = dayBoundsIso(date); // 00:00:00 — 23:59:59.999 в TZ браузера
useQuery({
  queryKey: ['location', 'history', childId, date],
  queryFn: () => locationsApi.getHistory(childId, from, to, 2000),
  staleTime: isToday(date) ? 30_000 : 5 * 60_000,
  refetchInterval: isToday(date) ? 60_000 : false,
  gcTime: 60 * 60_000,
  enabled: !!date,
  placeholderData: (prev) => prev, // keepPreviousData
});
```

- `date` формат `YYYY-MM-DD` в локальной TZ.
- Если `items.length === 2000` и `nextCursor !== null` → флаг `isTruncated = true` → `<TrackTruncatedBanner>`. Автоподгрузка `nextCursor` НЕ делается.

### Инвалидация

Нет write-операций на этом экране → `invalidateQueries` не используем.

### `child-map.tsx`

```ts
'use client';
import dynamic from 'next/dynamic';

const ChildMapInner = dynamic(() => import('./child-map-inner'), {
  ssr: false,
  loading: () => <div className="h-full animate-pulse bg-zinc-100" />,

```

`child-map-inner.tsx` импортирует `ymap3-components` и рендерит `<YMap>` с `<YMapDefaultSchemeLayer>` + `<YMapDefaultFeaturesLayer>` + дочерние маркеры/полилайны.

**Инициализация API:** скрипт `api-maps.yandex.ru/v3/?apikey=${key}&lang=ru_RU` подключается через `next/script` внутри `map-client.tsx` со `strategy="afterInteractive"`. Если в Phase 2 появится несколько страниц с картой — поднимем скрипт в `cabinet/layout.tsx`.

**Bounds/zoom:**

- При первом рендере, если есть `latest` → центр = `(lat, lon)`, zoom 15.
- Если выбран день и есть трек → `fitBounds` по всем точкам трека + `latest` (если есть) + padding 40px.
- Пользовательский pan/zoom НЕ сбрасывается при refetch: первый `fitBounds` за открытие экрана — через `useRef`, последующие обновления маркера обновляют только position.

### `stale-indicator.tsx`

Состояния по `ageSec`:

| `ageSec`    | Цвет    | Текст                                  |
| ----------- | ------- | -------------------------------------- |
| `< 60`      | зелёный | Обновлено N сек назад                  |
| `60..299`   | серый   | Обновлено N мин назад                  |
| `300..1799` | жёлтый  | Давно не обновлялось: N мин            |
| `≥ 1800`    | красный | Устройство не выходило на связь: N мин |

Дополнительно в плашке: `±{accuracy} м` (если не null) и `🔋 {batteryLevel}%` (если не null).

`role="status"`, `aria-live="polite"`.

### `latest-marker.tsx`

- Кружок-аватар: `avatarKey` → URL из MinIO (если есть), иначе первая буква имени на цветном фоне (как в `ChildCard`).
- Accuracy-circle: `YMapFeature` с `geometry.type = 'Polygon'`, аппроксимация круга 64 точками на радиусе `accuracy` метров (перевод метров → градусов с поправкой на `cos(lat)`). Заливка `rgba(59,130,246,0.15)`, обводка `rgba(59,130,246,0.4)`. Если `accuracy === null` — круг не рисуем. Хелпер: `apps/web/lib/geo/circle-polygon.ts`.
- Bearing-стрелка — НЕ рисуем в MVP.

### `track-polyline.tsx`

- `YMapFeature` с `geometry.type = 'LineString'`, координаты `items.map(p => [p.lon, p.lat])`.
- `stroke`: `[{ color: '#2563eb', width: 4, opacity: 0.9 }]`. Сплошная, без dash.
- Маркер start (первая точка): зелёный кружок 10px + текст `HH:MM` тултипом.
- Маркер end (последняя точка): красный кружок 10px + текст `HH:MM` тултипом.
- Если `items.length < 2` — polyline не рендерим, только маркеры (или ничего, если 0).

### `date-selector.tsx`

- Три `<button>`-чипа: Сегодня, Вчера, Позавчера. `aria-pressed` на активном.
- `<input type="date" min={today-30d} max={today} value={date} onChange={...}>`.
- Выбор чипа и инпута — один state `date: string` в `YYYY-MM-DD`.
- Sticky top, белый фон, тонкая граница снизу.

### `track-truncated-banner.tsx`

`role="status"`, жёлтый: «Трек обрезан до 2000 точек. Уточните диапазон, выбрав более короткий период.» + кнопка «Показать вторую половину дня» → ставит `from = today 12:00`, `to = today 23:59`.

Реализация «половины дня» требует режима произвольного диапазона часов — откладываем в Phase 2. В MVP — только текст баннера без кнопки.

### `map-error-fallback.tsx`

Показывается если `ymaps3` не загрузился (timeout 10с, или throw в `ready`):

- Текст «Не удалось загрузить карту Яндекса. Попробуйте обновить страницу.»
- Фолбэк на текстовый вид последней позиции: координаты, accuracy, время, кнопка «Открыть в Яндекс.Картах» → `https://yandex.ru/maps/?pt={lon},{lat}&z=15`.

## 8. Безопасность и приватность

- Все read-эндпоинты требуют JWT (проверяется в `/api/children/[id]/location/*/route.ts` через cookie-based auth как в других proxy-роутах).
- `FamilyAccessGuard` на backend защищает от доступа к чужим детям (404 `child_not_found`).
- Нет PII в URL / localStorage / query-cache beyond requirements.
- 152-ФЗ: данные не покидают РФ. Яндекс.Карты — российский сервис, хостятся в РФ. OK.
- Consent: backend проверяет согласие только на ingest. Read доступен всегда при валидном JWT. Баннер «нет согласия» на read-стороне НЕ показываем.

## 11. Риски

1. **Yandex API key rate-limit/обнуление в проде** → карта не грузится. Mitigation: `<MapErrorFallback>` с текстовым latest + «Открыть в Яндекс.Картах». Мониторинг: `window.ymaps3` error → GlitchTip.
2. **Мобильные браузеры задерживают `visibilitychange`** — принимаем, `refetchOnWindowFocus` покрывает.
3. **Таймзоны:** backend — UTC, UI — локальная TZ браузера. «Сегодня» у родителя за границей может отличаться от серверного дня. В MVP — используем локальную TZ. Настройка семейной TZ — Phase 2.
4. **`limit=2000` может не хватить в пиковый день** (ingest каждые 15с × 12ч = 2880). Mitigation: баннер-обрезка. В Phase 2 — client-side downsampling или server-side LTTB.
5. **`ymap3-components` — сторонний npm-пакет**, возможна задержка обновлений под новый v3 API. Mitigation: pinned version в package.json, fallback на `@yandex/ymaps3-reactify` (официальный) если уткнёмся.
