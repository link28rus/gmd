# GMD Phase 0.1 — Monorepo Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Создать рабочий скелет монорепо GMD — `pnpm install && pnpm dev` поднимает backend (NestJS + `/healthz`) и web (Next.js landing), есть заглушки Flutter-приложений, типичные конфиги (ESLint/Prettier/Husky/TypeScript/Prisma), инициализирован git + первый коммит + первый тег v0.1.0.

**Architecture:** pnpm workspaces + Turborepo для JS/TS; Melos — для Flutter (добавим в конце). Backend — NestJS 11 на TypeScript с Prisma 5 (схема пустая, только User-модель-заглушка). Web — Next.js 15 App Router. Пакеты `shared-types` (будет генериться из OpenAPI позже) и `ui` (shadcn base) — пустые с правильной структурой.

**Tech Stack:** Node.js 22 LTS, pnpm 9, Turborepo 2, NestJS 11, Next.js 15, Prisma 5, TypeScript 5.6, ESLint 9 flat config, Prettier 3, Husky 9, Commitlint 19, Flutter 3.x, Melos 6.

**Deliverable:**
- `pnpm install` отрабатывает чисто
- `pnpm dev` параллельно запускает backend (port 3001) и web (port 3000)
- `curl http://localhost:3001/healthz` → `{"status":"ok"}`
- `pnpm test` проходит (есть хотя бы 1 unit-тест на backend)
- `pnpm lint && pnpm typecheck` зелёные
- git репозиторий инициализирован, первый коммит, тег `v0.1.0`
- GitHub-ready (без пуша — push в плане 0.4 CI/CD)
