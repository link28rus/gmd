## App 1: GMD — Родительский контроль (mobile-parent)

**Package:** `ru.link28rus.gmd.gmd_parent`
**Возрастной рейтинг:** 0+

### Имя приложения (≤50 chars)

```
GMD: родительский контроль
```

### Краткое описание (≤80 chars)

```
GPS-локация ребёнка, геозоны, расписание блокировки приложений
```

### Полное описание (≤4000 chars)

```
GMD — российский сервис родительского контроля и геолокации детей. Аналог сервиса «Где мои дети» с self-hosted-инфраструктурой полностью на территории РФ.

Это приложение — для родителя. На устройство ребёнка устанавливается отдельное приложение «GMD для ребёнка» (тоже доступно в RuStore), которое подключается к вашему аккаунту по QR-коду.

ВОЗМОЖНОСТИ
• Карта в реальном времени — где сейчас ребёнок, сколько времени он там, как он туда добирался.
• История перемещений за последние 30 дней.
• Геозоны — отметьте на карте «Школа», «Дом», «Бабушкин дом». Получайте push-уведомление, когда ребёнок входит или выходит.
• Звук вокруг ребёнка — кратковременное прослушивание окружающего звука с устройства ребёнка по запросу из приложения. Полезно убедиться, что у ребёнка всё в порядке.
• Кнопка SOS — ребёнок одним нажатием отправляет вам тревожный сигнал с координатами на момент нажатия.
• Расписание блокировки приложений — задайте окна вроде «Сон 22:00-08:00» или «Уроки 09:00-14:00». В эти периоды на устройстве ребёнка автоматически блокируются все приложения, кроме разрешённых вами и звонков.
• Ручная блокировка — заблокируйте приложения на устройстве ребёнка одной кнопкой из любого места.
• Несколько детей в одном аккаунте — добавляйте по одному QR-коду на каждого ребёнка.

БЕЗОПАСНОСТЬ И ПРИВАТНОСТЬ
• Все данные хранятся на серверах в России (152-ФЗ).
• Передача за рубеж не осуществляется.
• Никакой рекламы, никакой передачи данных третьим лицам.
• Геолокация хранится не более 30 дней — затем автоматически удаляется.
• Удаление аккаунта одним нажатием в настройках; полное стирание данных через 30 дней.
• Шифрование канала TLS 1.2+, пароли argon2id, токены сессии httpOnly.

УСТАНОВКА
1. Зарегистрируйтесь по email — получите код входа.
2. Установите на телефон ребёнка приложение «GMD для ребёнка» (отдельно в RuStore).
3. В этом приложении (родитель) нажмите «Добавить ребёнка» — покажется QR-код.
4. Отсканируйте QR-код приложением ребёнка — устройство привязывается за несколько секунд.

ПОДДЕРЖКА И ПРАВА
• Политика конфиденциальности: https://gmd-online.ru/privacy
• Поддержка: link28rus@gmail.com (ответ до 30 дней по 152-ФЗ).
• Сервис управляется физическим лицом-разработчиком, серверы в РФ.
```

```
Подключите телефон ребёнка к родительскому контролю GMD по QR-коду
```

```
GMD для ребёнка — спутник-приложение для детских устройств в составе сервиса родительского контроля и геолокации GMD (https://gmd-online.ru).

Устанавливается на телефон ребёнка. Самостоятельно не работает — нужен подключённый родительский аккаунт через приложение «GMD: родительский контроль» (отдельно в RuStore).

ЧТО ДЕЛАЕТ
• Передаёт координаты устройства родителю (для отображения на карте у родителя).
• Принимает запросы родителя на блокировку приложений на время сна, уроков, прогулки.
• Передаёт кратковременную аудиозапись окружения по запросу родителя из его приложения.
• Отправляет тревожный сигнал SOS при нажатии ребёнком соответствующей кнопки.
• Защищён от удаления — без согласия родителя ребёнок не может удалить приложение.

ПРОЗРАЧНОСТЬ
• Не читает переписку в мессенджерах, не перехватывает SMS, не записывает телефонные звонки.
• Не блокирует экран устройства, не сбрасывает данные, не меняет пароль экрана блокировки.
• Не показывает рекламу, не сохраняет аудио постоянно (только сессионный буфер на время прослушивания родителем).
• Все собираемые данные хранятся на серверах в России (152-ФЗ).
• Полный список запрашиваемых разрешений с обоснованием — в Политике конфиденциальности (https://gmd-online.ru/privacy раздел 4).

УСТАНОВКА
1. Установите это приложение.
2. Откройте — увидите экран «Сканировать QR-код от родителя».
3. Родитель в своём приложении GMD нажимает «Добавить ребёнка» — показывает QR-код.
4. Отсканируйте — устройство привяжется к родительскому аккаунту.
5. Дайте запрашиваемые разрешения по подсказкам приложения. Каждое разрешение нужно для конкретной функции (например, «Спецвозможности» — для блокировки приложений). Без разрешений соответствующая функция работать не будет.

ОТКЛЮЧЕНИЕ
• Родитель может удалить устройство из своего кабинета — приложение перестанет передавать данные.
• Полное удаление приложения с устройства — после согласия родителя в кабинете либо через сброс к заводским настройкам.

ПОДДЕРЖКА
• Политика конфиденциальности: https://gmd-online.ru/privacy
• Поддержка: link28rus@gmail.com
```

## Поле «Обоснование разрешений» (для модератора RuStore)

Заполняется при подаче в Console в специальном поле «Дополнительная информация для модерации» / комментарий ревьюверу. Для child-приложения обязательно подробно описать каждое sensitive permission.

```
GMD для ребёнка — устройство-спутник в составе родительского контроля. Permission-набор обусловлен функциями родительского контроля и геолокации детей. Полный список с обоснованием опубликован в разделе 4 нашей Политики конфиденциальности: https://gmd-online.ru/privacy

Краткое обоснование наиболее чувствительных разрешений:

1. Доступ к местоположению (включая фоновый, ACCESS_BACKGROUND_LOCATION) — основная функция: показ родителю текущего и прошлого местоположения ребёнка на карте. Без фоновой работы геолокация выключилась бы при закрытии приложения, что делает функцию бесполезной. Координаты передаются на серверы в РФ, хранятся 30 дней.

2. Микрофон (RECORD_AUDIO + FOREGROUND_SERVICE_MICROPHONE) — функция «звук вокруг ребёнка»: родитель может из своего приложения запросить прослушивание окружающей среды для проверки безопасности. Активируется ТОЛЬКО по явному запросу родителя; на устройстве ребёнка показывается уведомление о начале сессии. Аудиоданные не сохраняются на серверах после завершения сессии прослушивания.

3. Специальные возможности (BIND_ACCESSIBILITY_SERVICE) — реализация функции «блокировка приложений по расписанию». При попытке ребёнка открыть запрещённое родителем приложение, наш сервис показывает поверх него экран блокировки с таймером. Сервис НЕ читает содержимое экранов, НЕ собирает вводимые тексты, НЕ перехватывает пароли. Реагирует только на событие «открыто новое приложение» и сравнивает имя пакета со списком ограничений, заданных родителем.

4. Администратор устройства (BIND_DEVICE_ADMIN) — защита приложения GMD от удаления ребёнком без согласия родителя. Без этого ребёнок может в один тап удалить приложение из лаунчера и обойти родительский контроль. НЕ используется для удалённой блокировки экрана, сброса данных или изменения политик пароля устройства.

5. Окно поверх других приложений (SYSTEM_ALERT_WINDOW) — отрисовка экрана блокировки приложения поверх запрещённого. НЕ используется для рекламы или сбора кликов.

6. Доступ к статистике использования (PACKAGE_USAGE_STATS) — отчёт родителю о том, какими приложениями и сколько времени пользовался ребёнок. Содержимое внутри приложений не читается; только имя пакета и длительность.

7. Игнорирование оптимизации батареи (REQUEST_IGNORE_BATTERY_OPTIMIZATIONS) — для стабильной работы фонового сервиса геолокации (без этого Android Doze глушит фоновые задачи через 15-30 минут).

Сервис разработан физическим лицом-разработчиком, инфраструктура полностью в РФ (Хабаровск). Соответствует 152-ФЗ. Контакт для вопросов: link28rus@gmail.com.
```

Для **mobile-parent** обоснование разрешений короче — он запрашивает только стандартные:

- Уведомления (push о геозонах, SOS, низком заряде ребёнка) — приёмная сторона FCM/RuStore Push.
- Доступ к интернету — обращения к API сервиса.
- Никаких особых разрешений уровня системы.
