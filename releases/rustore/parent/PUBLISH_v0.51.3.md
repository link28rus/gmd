# Публикация parent v0.51.3(27) в RuStore — инструкция

> **TL;DR:** залить AAB по адресу ниже, обновить три блока текста в wizard, нажать
> «Отправить на модерацию». Ключевое изменение — rebrand «GMD: родитель» →
> «Перископ Родитель» (`android:label`, `MaterialApp.title`, user-facing строки
> на экранах входа, добавления ребёнка, защиты от удаления). Никаких новых
> разрешений, никаких изменений бизнес-логики. Multi-use invite `AJGD3K2D` уже
> настроен на проде — модератор сможет тестировать неограниченное число раз.

## Артефакт

- **AAB:** `releases/rustore/parent/gmd-parent-0.51.3+27.aab`
- **Размер:** 46.4 МБ (Console покажет меньше для base.apk — это норма, см. FAQ в README)
- **SHA-256:** `857323e77b81639acfb28c15786e2ab176f7d40f689a4c15ebbc561d9819d7fa`
- **Подпись:** тот же keystore что и v0.50.4/v0.51.0 (cert DN `CN=GMD Parent, OU=GMD,
O=link28rus, L=Khabarovsk, ST=Khabarovsky Krai, C=RU`, SHA-1
  `41F11C564D4DE62BE4A3335F0910C344140479B0`). `jarsigner -verify` → `jar verified`.
- **Версия в RuStore Console:** 0.51.3 (27)

## Что изменилось vs v0.51.0(26)

1. **Rebrand «GMD: родитель» → «Перископ Родитель».** `android:label` и
   `MaterialApp.title` теперь показывают «Перископ» вместо «GMD». Имя бренда видно
   в системе (Settings → Apps, drawer launcher'а, task switcher, runtime permission
   dialogs). Package id `ru.link28rus.gmd.gmd_parent` не меняется — это та же
   запись в RuStore Console. Аналог rebrand'а child-приложения (v0.51.2,
   «Перископ Ребёнка»).
2. **User-facing строки «GMD» → «Перископ» / «Перископ Ребёнка».** Экран входа
   («Вход в Перископ»), экран добавления ребёнка («Откройте приложение «Перископ
   Ребёнка»»), диалоги защиты от удаления и пустое состояние списка детей теперь
   ссылаются на «Перископ Ребёнка» вместо «GMD». Внутренние debug-логи (`[GMD ...]`)
   не трогались — они не видны пользователю.
3. **Иконка не менялась.** Родительское приложение уже использует фирменный
   pin-маркер в синей (sky) палитре — он визуально отличается от зелёной (emerald)
   иконки приложения ребёнка, чтобы их было легко различать. Бинарно идентична
   предыдущей версии.

**Smoke-test пройден на AVD** (по lesson #41 release workflow, этап 1):

- AVD x86_64 (Medium Phone API 36, без GMS — то же что у модератора): запуск без
  crash'а, экран входа показывает «Вход в Перископ», `aapt2 dump badging` →
  `application-label:'Перископ Родитель'`, `versionName=0.51.3 versionCode=27`.
  В task switcher — синий pin-маркер.
- Этап 2 (реальное устройство по Wi-Fi) пропущен по решению — изменения только
  текстовые (label + строки + версия), бизнес-логика и разрешения не тронуты,
  предыдущая версия с тем же кодом уже отрабатывала на реальном устройстве.

### Шаг 2 — «Безопасность»

Permission-набор parent app минимальный — sensitive permissions не запрашиваются
(parent только показывает данные ребёнка, сам ничего не записывает на устройстве
родителя). Набор не менялся vs v0.51.0.

- **«Типы данных» (7/38):** ID устройства или другие идентификаторы • Имя •
  ID пользователей • Электронная почта • Взаимодействие с приложением •
  Диагностика • Отчёты об ошибках
- **«Обоснование разрешений»** — взять без изменений из `PUBLISH_v0.51.0.md`,
  шаг 2 (sensitive permissions parent не запрашивает; раздел может не показываться).

### Шаг 3 — «Информация»

Если поля сохранились с прошлой подачи — оставить как есть. Если сбросились
(RuStore wizard любит это делать), заполнить:

- **Название приложения:** `Перископ Родитель`
- **Тип:** Приложение
- **Минимальная версия Android:** 7
- **Основная категория:** Родителям
- **Возрастное ограничение:** 6+ — **проверить явно**, default сбрасывается на 0+
  (lesson #45: submit child 0.51.2 прошёл с 0+ в Page Record хотя в wizard было 6+;
  verify после approve через `https://console.rustore.ru/apps/2063713895` → блок
  «Категории → Возрастная»).
- **Поисковые теги (0/5)** — **ЗАПОЛНИТЬ ОБЯЗАТЕЛЬНО, default пусто:**
  - `перископ`
  - `родительский контроль`
  - `геолокация ребёнка`
  - `gmd` (legacy-пользователи продолжают искать по старому имени)
  - `геозоны`
  - **Why:** без явных тегов поиск «перископ» в каталоге RuStore возвращает ноль
    результатов, а «gmd» возвращает нашу карточку через legacy search-index
    (lesson #45). Теги — единственный способ покрыть оба запроса; их нельзя
    отредактировать self-service после approve, только новой submit'ой.
- **Краткое описание** (≤80):

  ```
  Геолокация ребёнка, геозоны, расписание блокировки приложений, SOS
  ```

- **Полное описание** (≤4000) — взять из `docs/rustore-store-listing.md` (раздел
  «App 1: Перископ Родитель → Полное описание»).
- **E-mail разработчика:** `link28rus@gmail.com`

## Инвариант после публикации

- Имя приложения в RuStore Console (Application Record) останется прежним до тех
  пор, пока модератор не пропустит submit с новым названием «Перископ Родитель».
  После approve обновится в каталоге при переиндексации (обычно в течение часа).
- Существующие установки (пользователи на v0.50.4) при auto-update через RuStore
  client получат уже «Перископ Родитель» в drawer без переустановки.
- Поисковые теги и возрастная категория — **проверить в Page Record после approve**
  (lesson #45: сбрасываются на default и не редактируются self-service).
